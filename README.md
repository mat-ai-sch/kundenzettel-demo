# Kundenzettel-Demo

Dieses Repository veröffentlicht `demo.kundenzettel.de` über GitHub Pages. Der Workflow baut die öffentliche Demo aus dem Quellcode von [`mat-ai-sch/kundenzettel-website`](https://github.com/mat-ai-sch/kundenzettel-website) mit `VITE_RUNTIME_MODE=preview`.

Es werden ausschließlich fiktive Demodaten veröffentlicht. Nach Änderungen am Website-Repository kann der Workflow über **Actions → Kundenzettel-Demo veröffentlichen → Run workflow** erneut gestartet werden.
